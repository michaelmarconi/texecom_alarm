# Home Assistant App: Texecom Alarm

## How to use

This app is currently just a bootstrap skeleton. When started it will print the
configured `message` (or "Hello World...") to the log, then exit — there's no real
Texecom logic yet.

## Configuration

### Option: `message`

Placeholder option to prove the config -> options.json -> `bashio::config` round
trip works. Will be replaced with real options (panel host/port, UDL password, MQTT
broker settings, zone/area mapping, etc.) as the app is built out.
